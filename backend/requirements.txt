# Optional AI supplement (services/ai_detection.py)

# ONNX Runtime replaces the previous torch + torchvision + ultralytics stack.
#
# Why: that stack could not run on a 512 MB instance. Importing torch alone
# costs ~250-300 MB RSS before a single image is processed, and the CPU wheel
# is ~180 MB installed (the default PyPI Linux wheel bundles CUDA and is
# ~730 MB). onnxruntime with yolo11n is roughly a fifth of that, which is what
# makes AI context viable on the free deployment tier at all.
#
# Consequences of the swap, all handled in ai_detection.py:
#   * the model ships as a pre-exported app/services/weights/yolo11n.onnx
#     (~10 MB, committed) instead of being downloaded at runtime — a cold
#     start needs no internet and cannot half-download a cache
#   * ultralytics' pre/post-processing is gone, so letterboxing, output
#     decoding and per-class NMS are implemented explicitly there
#   * the opencv-python conflict that forced the old two-step `--no-deps`
#     install disappears: onnxruntime has no opencv dependency, so a single
#     `pip install -r requirements.txt` is now the whole build
#
# Version floor rather than an exact pin: this project targets Python 3.13
# (backend/.python-version) and 1.20 is the first onnxruntime release with
# cp313 wheels. Pinning an exact version risks selecting one with no wheel
# for the deployed interpreter, which fails the build outright; the floor lets
# pip resolve the newest compatible wheel. Pin it once you have a known-good
# build log.
onnxruntime>=1.20,<2
